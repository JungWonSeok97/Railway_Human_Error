# CatBoost 대 로컬 LLM: 철도 인적오류(PSF·HEP) 예측 비교

측정: 2026-11-17(CatBoost 판정 기준), 2026-11-18(코레일 종사자 설문 기준), KISTI 한강(GH200). 표의 숫자는 `bench/report_tables.py`가 `results/expert/summary.json`에서 그대로 뽑은 값입니다.

## 요약
- **응답자끼리도 의견이 많이 갈립니다.** 같은 조건을 판정한 두 사람이 같은 수준을 고른 비율은 PSF에 따라 38~62%입니다. 그래서 한 사람의 답을 맞히는 정답률은 어떤 모델이든 60% 근처가 한계입니다.
- **CatBoost는 원래 모델이든 다시 학습한 모델이든 56~59%로 서로 같습니다.** 로지스틱 회귀(57.8%)와도 차이가 없고, 늘 가장 흔한 수준을 답하는 것(55.5%)보다 조금 높습니다. 시험 응답자 여럿의 다수 의견이 있는 시나리오에서는 65~70%를 맞힙니다.
- **LLM은 예시 없이 쓰면 44.5~49.6%로 CatBoost보다 확실히 낮습니다.** 차이의 95% 구간이 모두 0보다 아래입니다. 세 모델 모두 응답자보다 조건을 평균 0.30~0.47수준 더 나쁘게 판정합니다.
- **실제 응답 24개를 예시로 주면 큰 모델은 따라잡습니다.** Kimi K3.1 Pro는 56.7%로 고친 CatBoost(57.6%)와 통계적으로 같고, macro-F1(0.519)은 모든 모델 중 가장 높습니다. Nemotron은 54.1%, OpenJev는 52.1%입니다. 다만 다수 의견 시나리오에서는 LLM이 54~57%로 CatBoost(65.9%)보다 확실히 낮습니다. "대부분의 종사자가 고를 답"을 맞히는 데는 CatBoost가 낫습니다.
- **같은 설문 21,380건으로 미세조정하면 LLM도 CatBoost와 같은 수준입니다.** OpenJev는 59.0%(다수 의견 67.7%)로 CatBoost와 통계적으로 구분되지 않습니다. 반면 같은 데이터를 검색 예시로 읽게 하면 51.7~53.5%로 오히려 낮습니다(1-1장).
- **예시는 실제 분포대로 넣어야 합니다.** 수준마다 같은 수를 넣으면 LLM이 드문 수준을 너무 자주 고릅니다(Kimi 51.9%, Nemotron 49.4%).
- **비용은 CatBoost가 압도적으로 유리합니다.** PC CPU에서 문항당 약 7~9ms이고 항상 같은 답을 냅니다. Kimi는 노드 6대(시간당 6노드시간)에서 문항당 약 15초가 걸렸습니다.
- **원본 프로젝트의 문제 5가지를 고쳤습니다.** 환경 모델이 늘 "나쁨"인 원인은 설문 앱이었습니다. 낙뢰와 안개를 "발생할 경우"로만 물어서 생긴 문제라 설문 앱도 고쳤습니다. 다시 학습한 모델은 정확도가 원래 모델과 같으면서, 응답자가 반응하는 문항을 하나도 무시하지 않습니다. 자세한 내용은 [fixes/README.md](../fixes/README.md)에 있습니다.

## 1. 코레일 종사자 설문 기준 비교(2026-11-18)

### 데이터
- 코레일 종사자 396명(기관사, 작업자, 관제사, 승무원)이 무작위로 만든 조건(문항마다 보기 하나)을 보고 PSF 수준을 고른 답 26,416건입니다. 저장 기간은 2025-11-14~2026-04-17입니다. 원본에는 개인 정보가 있어 git에 넣지 않았고, 비식별 파일만 넣었습니다([data/README.md](../data/README.md)).
- 조건은 문항마다 독립적으로 무작위로 정해지므로, 보기별 평균 판정으로 그 문항의 영향을 바로 볼 수 있습니다. 예를 들어 "6시간 이내 수면"의 평균 수준은 0.77, "8시간 이상"은 0.47입니다(0 = 보통, 2 = 매우나쁨). 이 방향은 원래 웹앱이 보내던 값과 반대입니다.

### 방법
- **분할**: 응답자 단위로 학습 317명(21,380건)과 시험 79명(5,036건)으로 나눴습니다. 한 사람의 답이 학습과 시험에 동시에 들어가지 않습니다.
- **시험셋**
  - 시험 응답자의 답에서 PSF마다 120개를 실제 분포대로 뽑았습니다(960개). LLM을 포함한 모든 모델을 이 960개로 비교합니다.
  - 다수 의견 시나리오: 시험 응답자 3명 이상이 같은 조건을 판정했고 다수 의견이 갈리지 않은 시나리오 328개입니다(F.1 87, F.2 12, F.3 59, F.4 7, F.5 34, F.7 113, F.8 16; F.6은 해당 없음).
- **LLM**
  - 예시는 학습 응답자의 답에서만 뽑았습니다. 수준별 8개(PSF당 16~24개)와, 실제 분포대로 뽑은 24개 두 가지입니다.
  - 실제 분포 예시를 쓸 때는 "같은 조건에서 철도 종사자 다수가 고를 수준을 고르세요"라는 한 줄을 덧붙였습니다.
  - 온도는 0이고, Nemotron은 생각 모드를 껐고, Kimi는 `reasoning_effort=low`입니다.
- **CatBoost**
  - 원래 모델은 웹앱 그대로 쓴 경우와 보기 순서만 고친 경우 두 가지로 평가했습니다.
  - 고친 앱 모델은 문항 하나를 특성 하나로 쓰고 학습 응답자로만 학습했습니다. 하이퍼파라미터는 원래 모델에서 읽은 값입니다.
- **지표**
  - 정답률과 PSF별 층화 부트스트랩 95% 구간(2,000회)을 냈고, 고친 앱 CatBoost와의 차이는 같은 문항끼리 짝지은 부트스트랩으로 계산했습니다.
  - macro-F1과 QWK(순서를 고려한 일치도)는 PSF별 값의 평균입니다.
  - 판정 편향은 예측 수준에서 응답 수준을 뺀 값의 평균입니다(+면 더 나쁘게 판정).
  - HEP 배수 10배 이내: 960개에서 PSF마다 하나씩 뽑은 프로필 300개에 대해, 모델 판정으로 계산한 PSF 배수 곱이 응답 기준 배수 곱의 10배 이내인 비율입니다.

### 문항별 반응
모델이 각 문항에 응답자처럼 반응하는지 봤습니다. 한 문항의 보기만 바꾸고 나머지는 무작위로 둔 조건 300개에서 평균 판정 수준이 얼마나 움직이는지 재고, 같은 문항에 대한 응답자 평균과 비교했습니다(`bench/item_effects.py`). 응답자 평균이 0.10수준 이상 움직이는데 모델이 0.03 미만으로 움직이면 "무시"로 셉니다.

| 모델 | 응답자는 반응하는데 모델이 무시한 문항 | 거꾸로 반응한 문항 | 응답자와의 평균 차이 |
|---|---|---|---|
| 원래 모델(웹앱 그대로) | 7개: 장비 가용성, 컴퓨터 지원 시스템, 절차 유무, 장비 사용 지식, 실내 온도, 의사결정 대안 수, 추론할 정보량 | 2개: 수면시간, 절차 복잡성 | 0.033 |

원인은 두 가지입니다. 하나는 보기가 둘인 문항을 학습 때는 0/1, 웹앱은 0/2로 보낸 것입니다. 원래 모델은 "2"를 처음 보는 값으로 받아 "가용성 높음"과 같게 판정했습니다. 다른 하나는 문항 2~3개를 GMM 군집 하나로 묶은 것으로, 이때 한 문항의 정보가 사라졌습니다.

| Nemotron(노드 1대) | 15분 53초 | 약 0.26 |
| Kimi(노드 6대) | 45분 41초(기동 약 12분) | 약 4.57 |

### 해석
1. **개별 응답의 잡음이 크기 때문에 정답률만으로는 모델을 잘 구분할 수 없습니다.** 같은 조건에서도 사람마다 판단이 다릅니다. 모델은 같은 조건에 늘 같은 답을 내므로, 정답률의 상한이 60% 근처입니다. 모델의 차이는 다수 의견 시나리오와 판정 편향에서 더 잘 드러납니다.
2. **LLM은 일반 상식으로 위험을 더 크게 봅니다.** 예시 없이 쓰면 판정 편향이 +0.30~+0.47로, 응답자가 "보통"이라고 본 조건을 "나쁨"으로 고르는 경우가 많습니다. 실제 응답을 예시로 주면 편향이 줄어듭니다(Kimi +0.12).
3. **예시가 몇 개뿐이어도 Kimi는 개별 응답 정답률이 CatBoost와 같아집니다.** CatBoost는 21,380건으로 학습했지만 Kimi는 PSF당 24개만 봤습니다. 라벨이 적은 새 PSF나 새 직종에서 초기 판정을 할 때 쓸 만한 장점입니다.
4. **다수 의견을 맞히는 데는 CatBoost가 낫습니다.** CatBoost는 많은 답에서 조건별로 가장 흔한 판정을 배웁니다. 반면 예시 24개를 본 LLM은 판정 척도는 맞추지만 경계를 정확히 맞추지 못합니다.
5. **HEP로 바꾸면 차이가 다시 커집니다.** 배수 곱이 응답 기준의 10배 이내인 비율은 CatBoost 41.7%, Kimi(실제 분포 예시) 40.3%입니다. 다른 LLM 설정은 14.0~32.7%입니다. 늘 가장 흔한 수준을 답해도 47.7%가 나오므로, 이 지표는 응답 잡음의 영향이 큽니다.
6. **보기 순서만 고쳐도 원래 모델이 좋아집니다.** 작업부하(F.1) 정답률이 50.8%에서 63.3%로, 다수 의견 시나리오 정답률이 64.6%에서 70.1%로 올랐습니다.

### 권장
- **PSF 판정과 HEP 계산**: 고친 Railway_hep(문항별 CatBoost, 보기 순서 보정, HEP 합산 수정)를 씁니다. 환경(F.6)은 새 설문을 받은 뒤 다시 학습합니다.
- **LLM을 쓸 곳**: 판정 결과 설명, 사고 보고서 같은 자유 서술에서 조건을 뽑아 설문 입력으로 바꾸기, 라벨이 적은 새 항목의 초기 판정입니다. 초기 판정에는 Kimi에 실제 응답 예시를 실제 분포대로 넣고, 사람이 검토합니다.
- **더 시도해 볼 것**: 판정할 조건과 비슷한 실제 응답을 찾아 예시로 넣는 방식(검색 기반 예시)입니다. 다수 의견 시나리오에서 LLM과 CatBoost의 차이가 줄어드는지 볼 수 있습니다.

## 1-1. LLM에게도 같은 설문 데이터를 보여 준 비교(2026-11-18 오후)
1장의 LLM은 예시를 최대 24개만 봤고 CatBoost는 학습 응답 21,380건을 모두 봤습니다. 공정하게 비교하려고 LLM에게도 같은 학습 응답을 두 가지 방식으로 보여 줬습니다(시험 응답자의 답은 쓰지 않음).
- **검색 예시**(Kimi, Nemotron, OpenJev chat): 판정할 조건마다 학습 응답 중 다른 문항 수가 가장 적은 20개와, 똑같은 조건의 학습 응답 수(예: 보통 3, 나쁨 4, 매우나쁨 3)를 프롬프트에 넣었습니다. 시험 질문의 87%에 똑같은 조건의 학습 응답이 있었습니다(`bench/llm_eval.py --retrieval 20`).
- **미세조정**(OpenJev 27B): 21,380건 전부를 "조건 → 고른 수준"으로 LoRA(r=16, 256개 층) 1회 학습했습니다. 노드 1대(GPU 4장)에서 34분입니다. 학습 전과 후를 같은 방식(가능한 수준마다 답 문장의 확률을 계산해 가장 높은 것 선택)으로 채점했습니다(`ft/finetune_openjev.py`).

| 모델 | 한 사람의 답(960) | 95% 구간 | CatBoost와 차이(%p) | 다수 의견(328) | CatBoost와 차이(%p) | 판정 편향 |
|---|---|---|---|---|---|---|
| CatBoost(고친 앱) | 57.6% | 54.4~60.7 | 기준 | 65.9% | 기준 | +0.15 |
| **OpenJev 미세조정** | **59.0%** | 55.9~62.1 | −0.8 ~ +3.6 | **67.7%** | −2.1 ~ +5.8 | +0.14 |
| OpenJev 학습 전(같은 채점) | 49.0% | 45.8~52.1 | −12.5 ~ −4.9 | 52.7% | −19.2 ~ −6.4 | +0.43 |
| Kimi 검색 예시 | 53.5% | 50.5~56.6 | −6.7 ~ −1.5 | 57.6% | −12.5 ~ −4.0 | |
| OpenJev 검색 예시 | 52.9% | 49.9~55.8 | −7.5 ~ −1.9 | 56.4% | −13.7 ~ −4.9 | |
| Nemotron 검색 예시 | 51.7% | 48.5~54.7 | −8.6 ~ −3.3 | 57.0% | −13.7 ~ −4.0 | |

- **같은 데이터를 학습하면 LLM도 CatBoost와 같은 수준입니다.** 미세조정한 OpenJev는 CatBoost와 통계적으로 구분되지 않고, 판정 편향도 같아졌습니다. 로지스틱 회귀도 같은 수준이므로 차이를 만든 것은 알고리즘이 아니라 데이터입니다.
- **검색 예시는 도움이 되지 않았습니다.** LLM은 똑같은 조건의 학습 응답 중 가장 많은 답을 그대로 따랐습니다(Kimi 90%, Nemotron 82%, OpenJev 89%). 그런데 조건 하나에 모인 학습 응답은 몇 건뿐이라 그 다수결의 정답률이 50.5%(다수 의견 55.7%)에 그칩니다. 같은 문항에서 CatBoost는 56.4%(65.9%)입니다. CatBoost와 미세조정 모델은 비슷한 조건 전체에서 문항별 효과를 모아 배우므로 잡음이 평균됩니다.
- **비용**: 미세조정 LLM은 학습에 GPU 4장 34분, 판정마다 GPU가 필요합니다. CatBoost는 CPU에서 학습 몇 분, 판정 8ms입니다. 정확도가 같으므로 정량 판정은 CatBoost가 낫고, 미세조정 LLM은 판정 이유 설명이나 자유 서술 처리와 함께 쓸 때 의미가 있습니다.
- 자원(2026-11-18 오후): OpenJev 서빙 32분 51초(GPU 1장), Nemotron 31분 6초(노드 1대), Kimi 32분 51초(노드 6대), 미세조정 37분(노드 1대, 첫 시도는 메모리 부족으로 1분 만에 실패) 합계 약 4.6노드시간입니다.

## 한계
- **정답의 잡음**: 정답이 개별 응답자의 판정이라 잡음이 큽니다(응답자 간 일치 38~62%).
- **원래 모델의 학습 데이터**: 이 설문으로 학습했을 가능성이 높아 원래 모델의 시험 점수는 유리하게 나옵니다.
- **다수 의견 시나리오의 편중**: F.1, F.3, F.5, F.7에 몰려 있고 F.6은 없습니다.
- **환경(F.6) 데이터**: 낙뢰와 안개가 늘 "발생"이라 환경 판단의 실제 모습을 반영하지 못합니다.
- **LLM 설정**
  - 프롬프트는 한 계열만 썼고, 예시는 24개로 고정했습니다. 수백 개 예시나 검색 기반 예시는 시험하지 않았습니다.
  - Kimi는 `reasoning_effort=low`만 썼습니다.
  - 한국어 성능은 모델 제작사가 공식 평가하지 않았습니다.
